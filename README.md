# ⚡ A-ranger (안드로이드 화면 제어 & 매크로 자동화 스튜디오)

MacroDroid의 핵심 아키텍처(트리거 · 제약 조건 · 다중 액션 엔진 + 접근성 화면 제어 + 플로팅 오버레이 컨트롤러)를 바탕으로 설계된 맞춤형 안드로이드 자동화 앱입니다.

## 📂 작업 경로
- 프로젝트 루트: `/Volumes/M/A-ranger`
- 빌드 산출물(APK): `/Volumes/M/A-ranger/dist/A-ranger-1.0.0.apk`

## ✨ 주요 기능 (v1.0.0)
1. **화면 제어 (`ARangerAccessibilityService`)**
   - **좌표 터치 / 연속 광클**: 지정한 `(X, Y)` 좌표를 원하는 횟수·간격(ms)으로 정밀 터치
   - **화면 글자·버튼 찾아 클릭**: 좌표가 바뀌어도 화면의 텍스트(예: `"건너뛰기"`, `"확인"`, `"동의"`)를 탐색해 자동 클릭 (UI 노드 클릭 + 바운딩 박스 좌표 터치 하이브리드 폴백 탑재)
   - **화면 스와이프 / 스크롤**: 상·하·좌·우 프리셋 및 커스텀 좌표 스와이프
   - **텍스트 자동 입력**: 현재 포커스된 입력창에 지정한 문구 자동 타이핑
   - **시스템 네비게이션 동작**: 뒤로가기, 홈 화면, 최근 앱, 알림창, 빠른 설정창, 화면 잠금, 스크린샷 캡처

2. **화면 위 플로팅 리모컨 & 십자 좌표 조준기 (`FloatingOverlayService`)**
   - 다른 앱이나 게임 화면 위에 반투명 리모컨(`▶ 실행`, `⏹ 정지`, `🎯 조준`) 표시
   - **`🎯 조준` 버튼**: 화면 위에 드래그 가능한 **십자 타겟(`┼`)**을 띄워 원하는 버튼 위로 옮기면 해당 화면 절대 좌표 `(X, Y)`가 자동 저장되며, 매크로 액션 편집 시 원클릭으로 불러올 수 있음

3. **트리거 · 제약 조건 · 액션 규칙 엔진 (`MacroEngine`)**
   - **트리거(6종)**: 플로팅 리모컨 버튼, 화면 특정 글자 등장, 특정 앱 실행, 알림 수신(키워드), 주기적 타이머(초), 충전기 연결
   - **제약 조건(5종)**: 제한 없음, 현재 실행 중인 앱 일치, 화면에 특정 글자 포함/미포함, 충전 중일 때만
   - **실시간 실행 로그**: 매크로 발동 시각, 트리거 사유, 액션 단계별 성공/실패 내역 기록

## 🛠️ 빌드 및 휴대폰 설치 방법
```zsh
zsh /Volumes/M/A-ranger/scripts/build.sh --install
```
(USB ADB 연결 시 APK 설치와 동시에 접근성 화면 제어 권한, 플로팅 오버레이 권한, 알림 감지 권한을 자동으로 활성화합니다.)
